# Machine Learning Algorithms

A collection of Jupyter notebooks exploring core machine-learning algorithms with Python, NumPy, Pandas, and scikit-learn datasets.

## Notebooks

- `knn-lvq-linear-regression.ipynb` — K-nearest neighbours, learning vector quantization, and a gradient-descent linear regression implementation. The recorded results include **1.00 KNN accuracy**, **0.956 LVQ accuracy**, and a **24.18 mean squared error** for the regression task.
- `kmeans-pca-clustering.ipynb` — K-means clustering and principal component analysis, including 2D and 3D visual exploration of the data.

## Run it

Open either notebook in Google Colab or Jupyter, then run the cells in order. The notebooks use publicly available datasets and download any required source data during execution.

## Skills demonstrated

`Python` · `NumPy` · `Pandas` · `scikit-learn` · `KNN` · `LVQ` · `Linear Regression` · `K-means` · `PCA`
